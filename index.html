Como usar o projeto

  1. No TIA Portal V21, habilite o PUT/GET na CPU e mantenha os DBs com acesso padrão.
  2. Baixe hardware e software na CPU ou no PLCSIM Advanced 8, com a CPU em RUN.
  3. Instale a biblioteca e rode a interface:
pip install python-snap7
python snap7_gui.py

O IP padrão é 192.168.0.1, rack 0 e slot 1. A versão em linha de comando é o snap7_variaveis.py. Detalhes completos no README do repositório.
